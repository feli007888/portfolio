## Descripción

Este es un portfolio web personal desarrollado para mostrar mis habilidades, proyectos realizados y datos de contacto. Cuenta con diferentes secciones, modo claro/oscuro, efectos visuales y un formulario de contacto.

## Lenguajes y herramientas

* HTML
* CSS
* Bootstrap
* GitHub

## Bitácora de investigación

Durante el desarrollo consulté principalmente **W3Schools** y **Bootstrap** para aprender y resolver dudas sobre HTML, CSS y diseño. La mayor dificultad fue definir el diseño general de la página, especialmente los colores, tipografías y como hacer el diseño general. Fui probando distintas opciones hasta llegar al diseño final. Cuando no encontraba una solución, consultaba a la documentacion y de no encontrar una solucion clara, le preguntaba al profesor.
